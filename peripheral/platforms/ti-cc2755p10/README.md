# TI LP-EM-CC2755P10

Build candidate for the CC27xx family using the existing TI Zephyr environment documented in [CC2340R5 setup](../ti-cc2340r5/README.md). Confirm the exact board model before using this image.

From the peripheral directory, run:

```text
python build.py ti-cc2755p10
```

Use a short build_root on Windows as for CC2340R5. Hardware bring-up, programmer configuration, radio output and benchmark measurements are pending.
